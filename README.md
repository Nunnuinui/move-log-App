# Move Log

GPSと歩数センサーで、行った場所・移動した距離・歩数を端末内に自動記録するAndroidアプリです。

## できること

- **滞在の記録**：約100mの範囲に8分以上いると「滞在」として記録。地名に加えて、会場・駅・お店などの施設名（OpenStreetMap）も自動表示
- **移動の記録**：距離・最高速度と移動手段の推定（徒歩／自転車など／車・電車／高速移動／**新幹線などの高速移動**〈160km/h以上〉）
- **歩数**：歩数センサーで自動カウント。再起動しても継続
- **カレンダー表示**：Google Fit風の月／週／日の表示。歩数・距離・消費カロリーを切り替えでき、日をタップするとその日の記録へ。日の表示では時間帯ごとのグラフが見られ、棒をタップするとその時間帯の詳細（滞在・移動を含む）を表示
- **ヘルスコネクト連携**：過去の歩数・距離・カロリーを取り込み（Google Fit連携分など）
- **Google Takeout取り込み**：Fitのエクスポート（ZIP／日別CSV）から過去の記録を復元
- **地点名の手動編集**：「職場」「実家」など好きな名前を付けられる（近くの滞在にも一括反映）
- **非表示エリア**：自宅などは半径300mを非表示に登録でき、地名も出ず、マップ連携もしない。非表示エリア内の座標は外部サービスへ送らない
- **Googleマップ連携**：滞在をタップするとその場所をGoogleマップで開ける

データはすべて端末内のSQLiteに保存され、サーバーへ送信しません（施設名の問い合わせ時のみ座標をOpenStreetMapへ送信。非表示エリア内では送信しません）。

## ビルド

Android Gradle Plugin 9.4.1 / Gradle 9.6.0、minSdk 31。

- リリース署名は `signing.properties`（リポジトリには含めていません）から読み込みます。自分のキーストアで作成してください。形式は Material Files 上流プロジェクトと同じです。
- `gradle/wrapper/gradle-wrapper.jar` はアップロード手段の都合で含めていません。必要なら `gradle wrapper` で再生成してください。
